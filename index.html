Como Publicar no GitHub Pages

Hospede este projeto gratuitamente em 3 minutos

1
Crie um repositório no GitHub Acesse github.com/new, defina um nome (ex: equacoes-2grau) e marque como Public.
2
Faça o upload do arquivo index.html Salve este código exatamente com o nome index.html. Clique em "uploading an existing file" no GitHub e envie o arquivo.
3
Ative o GitHub Pages Vá em Settings ➔ Pages no seu repositório. Em Branch, escolha main (ou master) e clique em Save.
Pronto! Seu site estará no ar em poucos segundos no endereço:
https://seu-usuario.github.io/nome-do-repositorio
